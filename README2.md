Summary:
Linear Search is a simple searching algorithm that checks each element in the list one by one until the target element is found or the list ends
It works on both sorted and unsorted arrays, making it easy to implement but less efficient for large datasets.
Conclusion:
Linear Search is suitable for small or unsorted datasets because it does not require the data to be sorted.
so it becomes slower as the size of the data increases. It is best used when simplicity is more important than speed
